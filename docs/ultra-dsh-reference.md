# Gemini Ultra CLI：本地 DSH-purge 功能对齐

本次功能结构参考
[YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge)
1.1.71，作者小杨。功能对照来自本地解压的发布版。Gemini 侧采用原生 TypeScript 接入，没有执行参考项目的宿主补丁脚本。

| 本地 DSH-purge 能力    | Gemini Ultra CLI 对应实现                                       |
| ---------------------- | --------------------------------------------------------------- |
| 提示词编辑与多套规则集 | 控制中心「提示词与规则」，支持保存、逐条启停和移除              |
| 会话侧栏与演练台       | 输入 `演练台`、`/drill`、`/drill ui` 或 `/drill web` 打开浏览器 |
| 会话任务分发           | 网页提交进入同一个 CLI 会话，执行过程和审批仍在终端             |
| 资产、工件、补丁记录   | 展示当前会话事实库与补丁事务，定时同步                          |
| 环境就绪状态           | 按钮读取现有本机工具链检查结果                                  |
| 技能目录浏览           | 读取当前会话已发现的技能名称、说明与启停状态                    |
| 模型与运行设置         | 切换已配置模型、推理强度、Bypass 和演练授权记录                 |

自定义提示词和规则保存至
`~/.gemini/ultra-prompts.json`；再次保存前将旧配置备份到 `.bak`。支持通过
`GEMINI_ULTRA_PROMPTS_FILE`
指定独立配置。保存后在后续主会话和子代理生成请求中追加，不修改 Gemini 原生系统提示，也不影响压缩、路由等内部辅助请求。总开关关闭时保留配置内容。

控制中心绑定
`127.0.0.1`，优先使用 45678，端口被占用时自动选择空闲端口。访问地址中的随机凭证仅用于当前进程。用
`/drill stop` 关闭；CLI 退出时自动关闭。

本轮没有迁移 DSH 的安装包清洗、加密默认提示词、宿主重启、自有服务器登记、攻击路径评分或全部资产管理界面。它们与 Gemini 的运行架构及现有数据模型并不等同。没有开展真实模型付费调用或外部演练验收。
